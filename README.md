# Davide Carloni's Programming Portfolio

## Featured project: Accelerashot
> A stage-based first-person shooter with platforming elements built in Unreal Engine 5, where the player has to shoot targets to gain movement speed. Over time, the player gradually loses speed, so the objective is to maintain a fast pace to finish levels in the shortest possible amount of time.

I worked as a **Gameplay Programmer** for this project. My main responsibilities were:
- Developing the shooting system and its interaction with both targets and the player character.
- Creating the target objects, designing them in a scalable and designer-friendly way.
- Programming the scoring system that would assign a rank to the player after clearing a level.
- Handling the communication between these systems and the UI.
